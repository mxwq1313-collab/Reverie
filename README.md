# 思绪 · Reverie

**把聊天整理成可以阅读、检索和回看的本地档案。**

思绪是一款面向 Windows 的聊天归档桌面软件。你可以读取电脑微信中的可用记录，或导入已有文件，在统一界面中浏览私聊与群聊、查看图片和附件、搜索原文、导出离线副本，也可以按需连接 AI，围绕选定的聊天内容提问。

[下载 Windows 版](https://github.com/mxwq1313-collab/Reverie/releases/latest) · [使用指南](docs/USER_GUIDE.md) · [更新日志](CHANGELOG.md) · [反馈问题](https://github.com/mxwq1313-collab/Reverie/issues)

## 主要功能

| 功能 | 可以做什么 |
|---|---|
| 聊天归档 | 管理多个归档，切换查看身份，浏览私聊、群聊和群成员信息 |
| 电脑微信读取 | 检测账号、选择会话，读取本机可用记录，按批次保存并识别重复消息 |
| 文件导入 | 预览并导入受支持的 JSON、CSV、聊天交换文件和封存快照 |
| 图片与附件 | 查看可用图片、表情和 GIF，展开合并转发，预览图片并保存原文件 |
| 原文检索 | 按关键词、日期与会话筛选，查看搜索结果对应的原始上下文 |
| AI 辅助阅读 | 在 Codex 侧栏中对选定范围提问，通过消息引用回查证据 |
| 本地知识检索 | 为已归档私聊文本建立独立索引，可选连接本地 Ollama 服务 |
| 回忆与统计 | 随机打捞旧消息、按日期回看，查看聊天日历与活跃分布 |
| 离线导出 | 将所选范围导出为 HTML、TXT 和配套附件，便于长期保存 |

### 浏览对话，保留原文

- 会话按最近消息排列，消息按时间展示，保留发送者、消息方向、原始文字、空格和换行。
- 支持私聊与群聊浏览；群聊可查看成员及已归档发言统计。
- 关键词与日期可以组合筛选。当前身份的私聊支持跨会话检索，结果可定位到原会话，再返回搜索结果。
- 可以选择、复制消息原文，继续加载记录，并查看附件详情。
- 大量记录分批读取和绘制，图片按可见区域加载；读取进度、取消和结果计数在界面中显示。

### 查看图片、表情与合并转发

取得并验证过的图片和表情可以直接显示，点击后打开预览；GIF 支持播放与暂停，原文件可以另存。合并转发以聊天记录卡片展示，展开后可阅读内部消息和查看可用图片。

音频、视频和普通文件通过附件入口管理，可查看信息并保存原文件；能否直接播放取决于文件格式及运行环境。缺失、过期或无法解码的资源会标明状态，消息本身仍保留。

### 用 AI 辅助理解聊天

**Codex 侧栏**用于围绕聊天内容提问、梳理线索和分析沟通信息。先在设置中连接并登录，再选择允许读取的身份与会话范围。回答支持流式显示、历史回看、复制、保存，以及通过消息编号定位原文。

**语义检索**面向已归档的私聊文本，提供原文检索和引用回查。索引与归档分开保存，可更新或重建；可以使用离线字面检索，或连接你已配置的本地 Ollama 服务与模型。

**MBTI 辅助分析**可围绕选定聊天片段梳理表达与沟通倾向，列出原文依据、反向证据和待验证问题；同时提供官方资料与测评入口。聊天分析结果属于辅助参考。

### 回看那些值得留下的片刻

- **随机回忆**：左下角交错箭头入口打开小窗口，可按日期和关键词筛选，打捞、前后回看、复制、保存或回到原文。关闭后再打开会保留回看记录。
- **时光胶囊**：左下角沙漏入口，按日期找回对话，支持分页与原文定位。
- **聊天统计**：左下角柱形图入口，查看聊天日历、活跃时段、星期分布、连续活跃及消息、参与者和附件统计。
- **文字小工坊**：统计字数、查找替换、整理空格与空行，支持撤销、复制和保存整理结果。

## 下载与开始使用

1. 从 [Releases](https://github.com/mxwq1313-collab/Reverie/releases/latest) 下载 Windows x64 压缩包。
2. 完整解压，运行 `思绪.exe`，保留旁边的 `_internal` 文件夹。
3. 在 **工具 → 归档管理** 中新建归档，或打开已有归档。
4. 进入 **添加记录**，从电脑微信读取，或选择文件、目录预览后导入。
5. 回到 **聊天归档**，选择查看身份与会话，开始阅读和搜索。

从电脑微信读取时，需要微信已登录，并选择正确的账号和会话。默认读取所选会话在这台电脑上的可用记录，也可以缩小条数范围。读取与保存按批次进行，重新读取会识别重复消息；封存快照支持中断后继续导入。

不需要 AI 时，可以直接使用归档、阅读、原文搜索、回忆、统计与导出功能。AI 连接和登录可在需要时单独配置。

## 导出与备份

导出页可以选择当前会话、当前身份或整个归档。导出覆盖所选范围内的全部已归档内容，不受当前搜索条件和界面已加载页数限制。

- **HTML**：适合离线阅读，包含会话排版和可用附件的相对路径引用。
- **TXT**：保留文字和附件路径，便于检索、整理与长期保存。
- **配套附件与清单**：导出可用附件，记录文件大小和摘要；缺失资源明确标注。

归档使用本地 SQLite 数据库。备份时，请同时保存数据库及同名的 `数据库名.media` 文件夹。软件与数据可以分开放置，程序升级时保留已有归档。

## 数据与使用范围

- **本地归档，AI 按需连接**：归档文件保存在本机。使用 Codex 或 MBTI 分析时，问题及选定范围的相关文字会发送至 OpenAI；附件原文件不会自动上传。本地模型功能需要自行配置相应服务与模型。
- **可读范围以实际来源为准**：电脑微信读取依赖已支持的客户端、数据结构和本机已有记录，不保证包含手机或云端的全部历史。文件导入会校验已登记格式。
- **媒体取得与消息导入分别记录**：一条消息已归档，不代表其图片或附件原文件已经取得。缺失资源需要在微信中取得后重新读取，或使用界面中可用的补全功能。
- **统计与回答都有范围**：聊天统计基于已经导入的记录；AI 回答可能包含推断，应结合原文引用核对。当前身份的“所有私聊”范围不包含群聊。

## 界面与操作

支持浅色、深色、跟随系统及多种配色，可调整字体、字号、滚动速度、紧凑导航和动画。提供简体中文与 English 界面；消息原文和联系人姓名保留原样。

主要导航与状态使用文字，辅助入口使用独立图标。鼠标悬停或用 Tab 聚焦图标，可以查看功能说明。软件内置可搜索的离线帮助。

## 从源码运行

使用包含 Tk 的 Python 3.10 或更高版本。在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\python.exe -m wechat_archive.desktop
```

基础依赖用于启动桌面界面与文件归档。完整电脑微信获取组件及随附 Codex 运行组件的准备方式见 [Windows 构建流程](.github/workflows/release-windows.yml)；普通用户可直接使用发行包。

项目也提供命令行与只读扩展接口：

```powershell
.\.venv\Scripts\python.exe -m wechat_archive --help
```
