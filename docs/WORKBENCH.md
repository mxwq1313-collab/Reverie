## 启动

完整解压 Windows 目录包，双击 ChatArchive.exe，保留 `_internal` 文件夹。程序本身不需要安装 Python。源码界面入口为 `python -m wechat_archive.desktop`；`python main.py --help`、原 CLI、导入窗口和旧网页继续保留。

已有有效归档时直接进入聊天页，恢复有效的查看身份/会话。上次选择失效时回退到有效身份及其最近会话；没有归档时显示打开/添加入口，不创建数据库，也不获取微信来源。

| 一级入口 | 功能 |
|---|---|
| 聊天归档 | 身份切换、会话摘要、原文气泡、搜索/日期、上下文、分页、导出会话 |
| 添加记录 | 从电脑微信读取；导入已有文件；分阶段操作与真实结果计数 |
| 导出归档 | 全部/身份/会话范围，HTML/TXT，保存位置，显示时区 |
| 工具与设置 | 联系人/消息 CRUD、备份结构检查、导入/分析报告、归档位置/恢复、阅读设置、既有 Codex 助手 |

## 阅读与查询

左侧导航当前选中项有独立状态；中间会话列显示姓名首字占位、昵称、最近原文摘要、日期和次级消息数。只使用原服务已有字段，不获取或伪造头像。长昵称与摘要按实际字体宽度截断。窄窗口自动使用紧凑导航和较小会话列。

右侧收到的消息靠左、白色背景；自己的消息靠右、浅绿色背景。日期分组、姓名和 UTC+08:00 显示时间是次级信息。原文保留空格、换行和空行，长文本自然换行；每条可选择复制，右键支持复制选中文字或整条原文。没有发送微信消息的输入框。

搜索可按 Enter，范围为当前/全部会话。日期按钮展开 YYYY-MM-DD 起止范围（北京时间，包含起止日期）；清除筛选恢复原会话。黄色高亮只作用于显示，不改原文或导出。全部会话结果显示所属会话，点击“查看上下文”切回原私聊并定位消息，不受旧关键词/日期筛选影响。

页脚分别显示“全部匹配”和“当前加载”的数量。上下文页会说明起始偏移。加载更多保留已存在的消息控件及像素阅读位置；失败时保留已加载内容，可重试。修改筛选后点击加载更多会从新查询开始，避免混入旧结果。无归档、空归档、无会话、无匹配联系人/消息与加载失败分别提供合理动作。

## 添加与导出

电脑微信流程：检测账号 → 选择账号并连接 → 搜索/选择联系人及读取范围 → 读取并归档 → 查看结果。数据目录折叠为高级设置。仅用户操作触发来源读取；仍为最近 50/500 项或受原边界限制的全部电脑本地记录。

文件流程：选择文件/目录 → 预览检查 → 开始导入 → 查看结果。格式和严格模式折叠；CSV 账号标签/时区仅在 CSV 场景显示。结果首先显示新增、重复、失败、未支持但已保留四个指标，完整错误/技术信息按需展开。预览计数明确为预览，不等于已经入库。没有可靠计数时显示“—”，忙碌进度为不确定动画，不使用伪造百分比。

取消只影响本软件读取；事务提交期间继续等待，不中途打断写库。繁忙时禁用相关控件，失败后恢复操作。

会话右上角进入会话导出，一级入口可以导出全部归档。范围、格式、保存位置与显示时区明确可见。导出包含所选范围内全部已入库文本，不受当前页数、关键词或日期显示筛选影响。每次使用新目录，不覆盖既有输出。

## 模块与兼容

- application_window.py：四入口主壳、导航、繁忙/取消/恢复、响应尺寸。
- browser_panel.py：身份/会话/搜索/日期/分页、上下文和视图恢复。
- message_widgets.py：联系人卡片、可选择的原文气泡、显示高亮和批量排版。
- operation_panels.py：添加/导出/工具面板及阅读设置。
- operation_actions.py：迁出的既有控制器操作，不建立第二套写库流程。
- common_widgets.py / theme.py：折叠、滚动、真实结果卡，字体/DPI及浅色样式。
- application_controller.py：兼容保留原接口；只增加 JSON 视图/阅读设置、有效最近归档回退，以及只读消息上下文定位。

SQLite Schema 仍为 2，chat-exchange 仍为 1.0。数据库、导入校验/去重/事务、来源获取/拒绝边界、导出核心和旧网页资源/协议未修改。v0.7.0 Codex 模块保留，其 token_exchange_failed 网络故障仍未解决，本轮没有实际账号或模型验证。

字体优先 Microsoft YaHei UI，回退 Microsoft YaHei/Segoe UI/Arial。界面尺寸用逻辑像素转换，字体使用明确的 Tk 像素字号，避免把点数当作像素。默认正文 15、标题 20、辅助 12 逻辑像素；阅读字号可调 14–18。常规文字颜色的计算对比度达到 4.5:1。仅浅色主题。
