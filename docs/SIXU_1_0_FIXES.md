# 思绪 1.0 修复验收

2026-10-15。本次为已发布 1.0.0 的本地修复构建，版本号与 v1.0.0 标签保持原状；原发行包保留。

## 交付行为

添加页可直接导入项目归档副本，数据库与已核验附件一并复制；旧库兼容处理由添加流程完成，原件保留。消息为零的来源会话不进入读取。来源表格只显示会话/群成员、消息数和本人/成员占比，计数只在真正导入后展示。

Codex 统一从右上角应用图标打开，支持当前所选私聊或群聊。只读工具提供正文和附件类型/可用性等元数据，附件文件不上传。群成员权限、线程/回合匹配和历史版本授权继续校验。发送前读取检查失败会直接反馈，不能把工具失败伪装成总结成功。工具定义按官方 app-server 文档及已安装 0.153.4 JSON schema核对，显式使用 deferLoading=false；参考 https://learn.chatgpt.com/docs/app-server 。

“身份未映射”表示来源发送者编号没有可用账号映射。可确认的群发送者前缀用于恢复账号；无法确认的正文、附件引用与原始快照仍保留，以未映射身份显示，不算成本人。登记的系统通知显示为系统消息，不误计入发送者身份未映射。未登记消息类型作为来源记录呈现类型编号和可读内容，原始字节仍保留；并不等于所有专有编码都能播放。

聊天正文和联系人摘要去掉已确认的群传输发送者前缀；复制原文保留源内容。联系人占比自适应换行，去除贯穿空白列表的焦点边框，展开箭头跟随成员显示状态。重复的助手、新建/打开和手动升级入口已收敛；高级本地模型/语义检索与聊天字面搜索用途不同，继续保留。

## 验证边界

旧版已经跳过的消息需要重新读取原来源才能补入；同一来源ID会去重，不能从仅含旧归档的副本中凭空恢复原先缺失的记录。

所有测试归档、来源分片与渲染聊天均为合成数据。没有读取用户真实聊天库、上传聊天或调用真实模型生成回答。实际微信版本/来源获取和账号侧模型工具调用需在用户已登录环境中复核，离线RPC通过不等于真实推理质量已验证。未知数据库、加密/损坏来源和不能解码的专有文件继续明确拒绝或保留原件，不猜测格式。
