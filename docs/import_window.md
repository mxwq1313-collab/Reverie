## 使用

完整解压后双击 **导入数据.cmd**。启动文件自己切换到所在项目目录，支持中文和空格路径，不必先在 PowerShell 中执行 cd。

窗口包含：数据类型、来源文件/文件夹、目标归档库、CSV 账户标签/默认时区、严格模式、预览检查、开始导入、结果和报告、查看聊天按钮。

第一次可点“填入示例”，来源由当前数据类型决定，归档目标会改成独立 data/ui_demo.db。点击预览不会写库；点击开始导入才写入。重复数据仍由原去重系统跳过。

类型支持：标准 JSON、CSV、wechat-mock JSON、以及带必要元信息和登记 Schema 的 Android 明文离线 SQLite 快照。窗口不会增加解密或未知格式支持。选到 Android 元信息文件时会提示改选数据库或账号文件夹。

默认目标固定在项目 data/chat.db。选用已有归档会追加、复用并去重，不重置；未知库仍由原数据层拒绝。来源不能作为目标，预览失败不会写入。

“查看已导入的聊天”打开本次成功/部分成功的归档库，继续使用原本机浏览器。这里启动的服务由导入窗口管理，关闭窗口会停止；导入进行中暂不允许关闭，避免打断任务。

## 原截图的错误

提示符是 `PS C:\Users\Lenovo>` 时，`python -m cli` 会在那个目录查找 cli，`python main.py` 会查找那个目录的 main.py。项目没有安装为全局模块，故截图中的命令没有启动导入。

现在推荐双击入口。命令方式须从项目目录运行：

```powershell
python main.py import-ui
```

也可从任意目录运行 Import-Data.py 的完整绝对路径。别在 ZIP 内双击：Windows 可能只临时提取一个启动文件，缺少其余模块。
