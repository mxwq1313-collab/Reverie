# 窗口缩放、分栏与发送者身份修复验收

日期：2026-10-16。基于思绪 2.2.2 的本地修复构建，版本号保持 2.2.2。本轮未新建正式标签、未替换已有 2.2.2 发行资产、未推送 GitHub；本地提交与产物摘要写入包内 `release_manifest.json`。

## 实现与操作

### 窗口缩放与分栏

- Windows 原生移动/缩放开始和结束事件限定为本进程、本窗口。监听线程只传递状态，所有 Tk 操作在 GUI 线程完成。拖动期间保持编辑器与文本框原有尺寸，松开后统一适配；拖动中途停顿不会反复解冻、排版。
- 文字工具等较重页面在连续缩放期间，用本应用工作区的内存图像更新预览，临时隐藏并保留原控件，结束后恢复。截图仅针对自身窗口句柄，不采集桌面、不保存用户画面。较轻的聊天/帮助页避免位图工作；AI 输入超过 4000 字符时才启用较重路径。预取失败会退回原有控件路径。
- 会话列表与消息区、工作区与 AI 侧栏都增加 8 逻辑像素的分隔条。拖动显示位置线，松开时提交一次布局，避免每个像素都重排文本。分隔条聚焦后可用左右方向键移动，Home 或双击恢复默认。
- 会话列表宽度与 AI 宽度分别保存；窗口大小改变不会覆盖用户的宽度偏好。AI 宽度可超过之前 640 逻辑像素的上限，实际宽度仍受窗口及内容可读性约束。窄窗口抽屉也支持拖动和键盘调宽。
- 大字号下按工具栏实际需要限制最小列宽；消息页脚可以换行，避免“加载更多”越出列边界。原文、换行、选择范围、输入控件及撤销记录保留。

### 提示与快速模式

- 删除所有通用操作进度/结果浮框，包括账号检测、连接核验和加载联系人等提示。现有底部状态栏继续显示进度和结果，原有错误处理与进度条继续使用。
- 图标的悬停/键盘说明保留，Windows 使用原生透明色去掉圆角外侧的空白四角。
- 开启快速模式后，闪电、强度标题与填充使用紫色。动画开启时，强度条有流光；启用“减少动画”时保留低频、固定位置的颜色脉动。关闭弹层时停止动画，关闭快速模式时撤销快速模式效果。
- 动画只表达快速模式状态，不改变滑块实际档位、模型参数或下一次请求生效的规则。

### 图片和表情的发送者身份

本轮用户反馈为“图片能找到，发文件的人对应不到”。对用户指出的消息进行只读核验后，确认来源发送者 ID 尾部空格导致重复身份；同一归档已存在标准 ID 及正确昵称。

- 新来源读取先移除发送者 ID 边界空白，再做已有身份匹配；群聊已登记的传输前缀同样处理 ID 与冒号间空白。不会根据图片、人脸、昵称或消息内容猜测人物。
- 旧归档在读取时建立内存临时映射，仅处理已登记 `wechat:` 命名空间中、同一账号下的等价稳定 ID。优先使用标准 ID，复用已有有效昵称；消息列表、上下文、成员列表、保存的身份选择及 AI 只读查询使用相同映射。
- 原数据库行、消息 ID、时间、内容、来源摘要和媒体原文件均不迁移、不删除。只读连接启用 `query_only`，临时表位于内存。其他命名空间、其他账号、ID 内部空格及确实未知的发送者不会强行合并。
- 旧来源重新读取时，仅当恢复原始带空格发送者后能精确重建原来源摘要，才接受为同一消息。真正的正文变更仍按冲突拒绝，避免身份修复破坏去重。
- 用户反馈的具体照片已只读验证：发送者恢复为该账号内已有昵称，媒体文件可用；该次核验前后归档主文件摘要相同。验收未扩展读取其他会话，未启用 CDN、未向模型发送真实聊天。私有身份和媒体信息仅留在被忽略的本地证据目录，不进入本报告或源码。

## 缩放测量与边界

对比干净的 2.2.2 源码树与本次源码。四场景各做三轮新旧交替，共 24 轮；每轮 24 次窗口尺寸变化、8ms 事件循环心跳、800ms 结束等待。窗口可见、置顶，使用自建数据；测量时没有并行测试或打包。保留全部轮次。

| 场景 | p95 延迟中位数：之前 → 本轮 | 每轮最大延迟中位数：之前 → 本轮 | 所有轮次最差延迟：之前 → 本轮 |
|---|---:|---:|---:|
| 普通聊天 | 52.782 → 56.119 ms | 64.349 → 58.738 ms | 65.577 → 63.496 ms |
| 合并转发 | 49.914 → 51.979 ms | 57.414 → 56.354 ms | 60.071 → 64.598 ms |
| AI 侧栏 | 50.761 → 50.740 ms | 56.423 → 57.773 ms | 58.009 → 68.446 ms |
| 文字工具 | 119.041 → 59.356 ms | 122.233 → 110.938 ms | 125.050 → 112.887 ms |

文字工具三轮都完成 24 次预览更新，共 72 帧；单次预览绘制回调最大 16.131ms。每轮总用时中位数从 3.420 秒降至 2.153 秒。轻页面没有启用位图路径，其测量有小幅波动，不能声称同等改善。

这些数值测量 GUI 事件循环延迟，**不等于显示帧率**。程序化尺寸变化及系统事件注入验证了缩放生命周期与停顿不解冻；截图验证了对应画面。仍有首次捕获、恢复及系统窗口管理造成的延迟峰值，尚不能承诺所有机器、所有页面“零卡顿”或稳定 60fps。日常实际拖动和高 DPI、多屏长期使用体验仍需使用反馈。
