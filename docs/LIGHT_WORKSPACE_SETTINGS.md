# 轻量工作区与设置

2026-10-14，基线133f5d8，分支feature/archive-platform-v0-9，内置版本保持0.8.0。

## 阅读与操作

截图圈出的原生厚滚动条改为7逻辑像素的平面细滑块，内容不需要滚动时隐藏滑块；支持拖动、轨道翻页、方向/Page/Home/End键及已有滚轮路由。主分隔带变窄，用聊天/导航/AI区域的轻色差分区。按钮和输入减少外框。空闲时进度和取消按钮不出现，处理时只显示真实工作状态；没有伪造百分比。

AI侧栏只显示当前聊天范围、对话操作、回答和输入。连接/登录/退出/检查、运行组件、范围/模型刷新和本地模型地址/选择统一移至设置→AI连接与模型。侧栏设置按钮可直接进入该页；既有认证门槛、授权范围、流式阅读、引用和重试继续复用原管线。

## 可以更改的设置

| 项目 | 实际行为 |
|---|---|
| 主题 | 浅色、深色、跟随Windows应用主题；即时生效，系统模式每2秒只读复核 |
| 字体与字号 | 使用已安装非竖排字体，字号12–24逻辑像素；原文、标题和控件同步更新 |
| 语言 | 简体中文与English；界面标签、选择项、日期组和提示本地化，选项底层值及聊天/姓名/回答原文保留 |
| 阅读/布局 | 滚动速度24–120、紧凑导航、恢复最近归档、减少动画、AI侧栏默认可见 |
| 文件 | 默认存储根、默认导出目录/HTML/TXT格式；新归档/来源捕获/报告/索引使用新根，原归档和旧文件保留原位 |
| AI | Codex组件/范围/模型选择及本地服务/模型选择可保存；登录与配置固定在原配置目录，存储更改不迁移凭据 |

设置中的目录使用本机绝对路径，保存前用独占新建的临时探针验证可写，随后移除探针；不接受文件位置或网络URL作为存储目录。设置写入采用同目录临时文件原子替换，保留既有字段。数据操作中不修改设置，AI或索引进行中不重定向文件根。正常运行不会搬运旧文件。

界面语言不会翻译归档内容、联系人姓名、模型回答或诊断报告；第三方组件返回的技术诊断可能保留原语言，Windows原生文件对话框使用系统语言。

## 可用工具

工具区显示归档管理、导入与分析报告、原文检索。移除重复“Codex助手”占位标签及不能用于聊天归档的备份文件头/有限载荷诊断标签；文件格式选择不再展示不支持正文导入的备份类型或模拟示例格式。底层导入/诊断和旧入口别名继续保持兼容，未知/加密格式仍拒绝。

未配置并确认本地模型时隐藏本地模型回答按钮；无需模型的离线原文检索可使用。模型配置与实际回答质量分别验证，不宣称真实账号、服务或模型推理通过。
