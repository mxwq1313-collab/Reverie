## 实施与回归发现

- A：按变化消息更新尾部，Markdown/引用局部标注；130ms 合并流式刷新，完成立即刷新；释放旧 Tcl 绑定，保留选区、阅读位置和主题切换位置。

- C：共享菜单，按时间创建，一页统一布局，只处理脏气泡；二分查可见行；有界真实子窗口；同步到增量的完整迁移；离屏只改布局数据；未见过的行以固定基准估高，防止反复拖动累积空白。
- D：隐藏管理树仅标记 dirty，进入页面后分批构建；上下文联系人放入后台读取并校验身份/源 token；返回搜索复用原联系人快照。
