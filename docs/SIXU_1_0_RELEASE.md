发布日期：2026-10-15（Asia/Shanghai）。此版本由用户明确要求发布，版本号与Windows产品信息统一为1.0.0。源码提交、v1.0.0标签与发行文件的对应关系写入发行包release.json；此前0.8.0产物保留。

## 使用者可见的变化

| 功能 | 1.0行为 |
|---|---|
| Codex历史 | 时钟图标与保存、设置同栏；自动保存在本机，可搜索、离线查看，范围及原文版本一致时恢复原线程继续提问 |
| 模型与努力程度 | 输入区下方使用一个组合入口，在同一面板调整；下一次发送起生效 |
| 会话范围 | 归档、身份、范围、会话搜索与消息占比集中在一个面板，应用后才切换 |
| 群聊联系人 | 来源列表以群名折叠成员；归档会话也可展开成员与各自发言比例 |
| 本人占比 | 当前查看身份发送数 / 会话全部消息数；文字与非文字均计入。来源列表和已归档列表分别统计各自范围 |
| 表情与文件 | Unicode原文、图片、GIF动图、音频、视频及任意二进制文件可归档；图片/动图可预览，原文件可另存，离线导出包含附件副本 |
| 帮助 | 分层标题、步骤、说明与搜索；窄窗口改用章节下拉选择，中英文文档同步 |

## 升级与备份

1. 直接启动思绪.exe，保留同目录_internal文件夹，无需另外安装Python。
2. 新建的桌面归档使用Schema3。旧Schema1/2仍可阅读；要保存群聊、表情和附件，在“设置 → 文件与存储”创建新的升级副本，原库保留。
3. 备份时至少包含数据库及同名的数据库名.media目录；完整保全还应包含存储目录内sources原始来源与配置目录内ai_history对话历史。
4. 普通旧JSON/CSV、交换1.0和原有API仍按既有规则工作；富消息使用明确登记的思绪交换2.0或封存批次目录，不能把未知微信文件当成该格式。
5. 老版本程序不能读取扩展归档。关闭程序后再复制或移动完整归档及其附件目录。

## 数据与边界

- 本人是当前查看身份，不按微信昵称猜测。群成员名称可重复，来源会话保留稳定标识。无法识别发送者时保留原始记录，来源列表对已识别份额标注下限。
- 可用附件记录相对路径、类型、大小、SHA-256及原图/压缩图/缩略图类别。大文件列表采用轻量检查；打开、另存与导出前核对摘要，拒绝路径越界、链接以及内容变化。
- 图片内嵌预览有16MiB和像素预算，单页有预览数量预算；其他图片可点击预览。GIF支持播放/暂停。专有图片容器和语音/视频编码可能需对应查看器；保存原文件不代表本软件解码所有编码。
- 微信本地媒体读取复用固定wechatauto-replica 1.2.6.1的已校验DB及媒体模块，解密与消息解析分层；只调用本地获取方法，不驱动微信界面下载，不持久化提取密钥。未知结构仍拒绝；未下载、已过期、原文件缺失或解密失败会标注缺失并保留消息。
- Codex工具仍只查询明确授权的已归档私聊文字；1.0新增群聊、媒体不自动扩大AI读取范围，也不自动上传附件。真实模型输出质量不由本次界面验收证明。
- 历史保存从1.0开始；旧版临时线程没有保存过的内容不能凭空恢复。离线快照始终可查看；继续原线程要求连接登录、范围一致、归档原文版本一致且服务端线程仍可恢复。
- 历史恢复采用[Codex App Server官方线程接口](https://learn.chatgpt.com/docs/app-server)，并以当前本机组件的ThreadResumeParams登记字段核对参数；不会扫描本设备主Codex账户的其他任务。
