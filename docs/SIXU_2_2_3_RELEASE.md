# 思绪 2.2.3 发布与验收

日期：2026-10-17。用户在知悉剩余缩放卡顿后明确要求创建发行包并发布 2.2.3，目标仓库为 mxwq1313-collab/Reverie，标签 v2.2.3。

## 本次更新

- 删除文字小工坊；随机回忆迁回“工具”页标签，保留范围筛选、打捞、前后回看、复制、保存和原文定位。左下角保留时光胶囊与统计入口。
- 稳定图标提示框：每个主题实例只显示一个提示，快速进出、点击、窗口移动、缩放和关闭均取消过期回调；提示位于目标旁并限制在屏幕内，Windows 下不抢焦点。
- 窗口与分栏调整持续使用真实控件，移除整个工作区的截图拉伸和隐藏/恢复路径。合并布局请求，按实际分栏尺寸适配，保留正文、选区和控件。
- 两条原生分隔条实时调整布局，移除深色代理拖动条；AI 自定义手柄合并高频更新，松手只保存一次，取消、失焦或关闭释放鼠标捕获，避免被旧宽度拉回。
- 自定义 ttk 背景预合成完整重复周期，减少大量小块 GDI 平铺；保留原有花纹、边界像素、字体、颜色、圆角与阴影。
- 修复首次布局的迟到滚动恢复覆盖用户新滚轮位置，以及弹层销毁后助手轮询访问失效控件。
- 包含此前本地分栏边界与媒体发送者身份修复：规范化来源 ID 的尾部空格，在同账号和明确命名空间内复用身份，不猜测未知发送者，不修改原始消息。

## 已知问题

**连续拖动窗口边框或内部分隔条仍可能有可感知卡顿，本版不宣称已经彻底解决闪烁或达到固定帧率。** 普通候选人工反馈为“黑条消失，但仍明显卡顿”。

PostMessage/Tcl idle 原生绘制合并实验曾得到更低计时间隔，但存在标题残缺、闪块或布局异常，因此没有启用到正常应用。没有关闭硬件加速、修改驱动或用整页截图替代真实布局。详细诊断历史见 [渲染排查记录](https://github.com/mxwq1313-collab/Reverie/blob/main/docs/SIXU_2_3_0_READINESS.md)；其中 2.3.0 是先前排查目标，不是本次发行版本。

## 下载与使用

下载 `Sixu-2.2.3-Windows-x64.zip`，完整解压后运行 `Sixu/思绪.exe`，保留 `_internal` 文件夹。发行包包含固定并校验过的 Codex 运行时、使用说明、发行清单和本说明；不包含个人聊天、数据库、微信密钥或登录状态。资源未取得时继续如实显示缺失。

应用、项目包与 Windows 文件/产品版本统一为 2.2.3。线上 Release 的 ZIP 与 SHA256SUMS.txt 是正式资产；本机与 CI 二进制摘要分别记录。只有实际 Release 与资产存在才代表发布完成。
