# 可读存储（v0.5.6，2026-10-13）

SQLite 归档用于查询、去重和继续处理；HTML/TXT 是可以独立打开的阅读副本。两种文件不依赖微信、提取工具或本机网页服务。本次从已验收的真实归档导出一个私聊的 38 条文本，不重新获取微信数据。

## 窗口操作

重新打开 `导入数据.cmd` → 在“目标归档库”选择已有档案 → 点击底部 **导出可读文件** → 选择保存位置。系统自动创建 `聊天导出_时间_随机标识` 子目录，避免覆盖已有文件。此操作不要求选择来源，也不重新导入。

在保存目录中双击 `index.html`，再选择会话阅读。也可直接打开 `chat_用户ID_用户ID.html` 或 `.txt`。HTML 可用浏览器自带查找、打印；TXT 为 UTF-8，可用文本编辑器阅读和搜索。生成过程不自动访问浏览器。

## 命令行

从完整解压后的项目目录运行，保存目录必须是新目录：

```powershell
python -m cli --db data/real_wechat_verified.db export-readable "D:\chat_exports\readable_20261013"
```

默认导出归档内全部私聊/笔记文本和两种格式。可限定双向私聊：

```powershell
python -m cli --db data/real_wechat_verified.db export-readable "D:\chat_exports\one_private_chat" --user 1 --peer 2
```

ID 是归档中的参与者 ID，可用 `python -m cli --db data/real_wechat_verified.db user list` 查看；不填 ID 则按全部会话输出。`--format html` / `--format txt` 可单选格式。`--timezone +08:00` 控制显示偏移，默认 +08:00；UTC 原时间仍保留在 HTML time 属性，数据库不改变。偏移为固定时区，不自动推断夏令时。

## 文件与数据约定

| 文件 | 用途 |
|---|---|
| index.html | HTML 离线会话入口；TXT 单选时不生成 |
| chat_A_B.html | 按原时间、消息 ID 排序；双方名称、参与者 ID、方向、原文和完整显示时间 |
| chat_A_B.txt | UTF-8 文本，同一范围和顺序，原始空格/换行/Unicode 保留 |
| manifest.json | 来源归档名称/版本、导出范围、显示偏移、会话和消息数量、文件长度和 SHA-256 |

文件名使用数据库参与者 ID，昵称不参与路径，避免同名或非法字符覆盖。名称与稳定身份在文件中列出；不会猜测谁是“我”。指定 `--user` 时仅调整显示方向，原发送/接收 ID 不变。

HTML 内容经转义，不执行消息中的 HTML/脚本，不加载头像或外部资源。本文本阶段不导出图片、视频、语音、群聊或来源隔离记录。遇到未支持的库类型/非文本/异常时间明确失败，不能静默少导。

## 原库保护与范围

导出用 SQLite `mode=ro` 和一致性读事务；读取项目 application_id 和版本 1/2 Schema，不调用初始化或迁移。缺失数据库不会被自动创建，未知 SQLite 不尝试解释为微信数据库。保存目录不接受网络路径、链接/目录联接或 `..`，已存在目录明确拒绝。

写入本次独占临时目录，全部成功后发布为新目录；失败清理前核对临时目录范围。不会覆盖以前导出、归档库或微信原库。按游标顺序写入全部所选记录，不受网页 50 条分页限制。

导出范围是**已入库文本**，不会补齐电脑上没有的手机记录。此前 12 条未支持来源记录仍保存在来源 JSON/导入报告里，没有变成可读文本。全历史获取、多账号选择等主线待办维持未完成状态。
