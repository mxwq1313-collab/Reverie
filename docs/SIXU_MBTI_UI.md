# 思绪界面精简与 Codex MBTI 验收

2026-10-15，分支 `feature/sixu-mbti-ui`。正式版本保持 1.1.0，本次为独立的本地“界面与MBTI版”构建，不创建新的正式版本标签。

## 本次行为

- 内容明确的文字按钮不再出现重复说明。图标按钮保留可访问名称及鼠标/键盘提示，提示改为主题配色的浅底圆角浮层。
- 聊天中的可用图片按比例直接展示，移除外框、文件名、附件信息及常驻操作。单击或聚焦后按 Enter 打开查看窗口，再查看尺寸、播放 GIF、保存图片与原文件。同条消息的原始容器归入“其他附件 / 原文件”。缺失资源和普通文件保留状态；无法解码的图片可在点击后的详情中保存原文件。
- 顶部左侧改为版本号，旁边保留归档名。顶部新建、打开按钮移除，在“工具 → 归档管理”仍可操作。聊天头部的导出按钮减轻视觉重量；消息搜索分为输入和范围/日期两行，空值提示明确用途。
- Codex 界面不再重复显示“你 / Codex”角色文字。问题靠右，回答靠左，底色区分；复制、保存和历史仍保留对话语义。生成状态前面的圆点移除，仅“千丝万绪”后面的圆点轮换；减少动画设置下放慢更新，完成、停止和断线后清除。
- Codex 图标旁新增 MBTI。当前会话可选择本人、私聊对方或实际群成员；全部私聊只分析当前身份本人，仍不包含群聊。分析继承当前关键词、日期筛选和归档权限；归档、会话或原文变化后旧弹窗拒绝发送。
- MBTI 使用现有 Codex 登录、模型、努力程度、只读工具、消息引用和历史。每次开启独立对话；界面显示简洁任务说明，完整任务指令随请求发送，失败重试保留指令。报告要求对象本人文字、实际读取数量/时间/遗漏、四维倾向、反向证据、置信度与待验证问题；证据不足保留未定，不伪造概率或正式测评结论。

## 使用

运行交付目录中的“思绪.exe”，保留同目录 `_internal`。在归档里选定会话，先清除不需要的关键词和日期筛选。连接 Codex 并登录 ChatGPT，点击右上角 MBTI，选择读取范围和对象，再点击“由 Codex 分析”。结果在右侧 Codex 中展示，可回查引用、保存或追问。

本次不读取、上传或修改用户真实聊天用于测试。协议和自建夹具通过只能证明流程接通，不能证明真实 MBTI 推断质量；模型可用性与输出受当前账号、模型和证据覆盖影响。
