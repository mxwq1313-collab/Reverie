# 思绪：大归档响应、缩放重绘与轻量界面

2026-10-15，基于64c6110继续，正式版本保持1.1.0。

## 已定位并处理的开销

浏览器此前每次创建只读访问对象都会重复进行整库结构和外键检查；20万条自建消息的一组读取中共校验23次。现按归档文件和WAL的身份、大小、修改时间及状态时间复用校验对象，变化后重新校验；查询结果仅在本机内存中有限缓存，归档与身份、会话、筛选和分页分别绑定，返回副本。未写入或迁移原归档。

默认启动、打开归档、聊天搜索和会话切换的读取在可替换的后台读取器执行，最多一个正在执行和一个待执行请求。旧查询可由新请求取消，SQLite读取有中断检查；结果回到界面前再次核对文件版本及当前筛选。控制器直接调用仍保留同步接口，用于既有服务、工具及明确的程序流程。关闭窗口后取消读取并丢弃结果。

联系人查询的最新消息改为沿现有会话时间索引定位，避免排序全部正文；重复筛选复用当前身份的已读会话摘要。另修复富媒体分页附件分批查询覆盖offset变量的问题，深页偏移和has_more现在保留真实值。

默认客户端的联系人和消息控件采用小批次创建、清理；离屏消息收起内部控件并保留行高，返回可见范围时恢复。缩放时使用离屏测量控件计算隐藏行换行，不把全部消息临时展开。已有图形复用Canvas项目，圆角向量复用；连续尺寸变化合并布局，文本测量不再把实际文本窗口临时压到1像素高。图片完成只合并更新滚动区域，无需重新测量全部文字；同一主题下不再随宽度变化重复遍历整条时间线重设颜色。

图片在布局完成且接近可见区域后才请求预览，最多两个解码任务、24个等待条目；相同源文件和尺寸共享解码，排队项使用弱引用过滤离屏或已销毁控件。PIL读取、摘要校验和解码在工作线程，Tk图片在主线程分批更新；JPEG使用解码缩放。缓存上限32张及16MiB像素，源文件状态变化不复用旧图，空闲时停止轮询。

## 界面与交互

减少重复圆角矩形，辅助按钮去除常驻边框，常规按钮使用浅底边阴影，输入和选择使用浅底与细底线；模型入口和主要输入保留有意义的圆角层次。右上角Codex入口去框；主界面隐藏归档文件名，范围和统计使用“当前归档”等含义说明，实际路径仍在归档管理中用于定位文件，存储、引用和导出标识保持。

按钮具有悬停、按压和键盘焦点反馈，页面切换使用细导航侧标；启用动画时侧标轻微移动，减少动画时直接到位。动画可取消，不以整页移动、拉伸或淡入阻挡输入。窗口先构建再显示，避免暴露未准备好的初始内容。
