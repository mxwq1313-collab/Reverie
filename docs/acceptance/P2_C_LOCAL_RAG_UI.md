# P2-C 本地证据问答与界面验收

日期：2026-10-14。基线 0eaead9，feature/archive-platform-v0-9；正式版本仍 0.8.0。

## 用户流程与交付

在聊天归档选择身份/会话，打开工具与设置→本地知识问答。离线字面检索默认可直接运行，点击更新索引后检索原词，列表逐条重新回查原文。需要模型时展开配置、读取已有本地模型并分别选择向量/回答模型。只有点击本地模型回答才会把检索到的当前范围原文交给本机服务。Codex 助手保留独立入口。详见 [使用说明](../LOCAL_KNOWLEDGE.md)。

RAG 检索→范围与原文核对→生成→结构化引用校验→重新核对消息/整个范围版本。使用 [Ollama 官方 chat 接口](https://docs.ollama.com/api/chat) 的非流式 JSON Schema 输出。每个结论必须附现有证据 ID，缺失/未知/伪造/超长回答拒绝，空证据不调用模型。模型可返回证据不足；回答明确属于推断，程序仅能核验引用来源与版本，不能证明结论蕴含关系。

UI 后台操作有取消/进度，取消后等待当前请求返回再释放，不重叠启动；切范围/设置/归档变化立即清除结果。复制和新文件保存前重读证据，模态保存对话后再次检查，拒绝覆盖现存文件。服务配置不含 API 密钥，不自动打开浏览器或下载模型。

## 验证与限制

新增 8 项问答测试、6 项 Tk 工作流测试。覆盖授权原文/提示数据隔离、无证据不调用、引用拒绝、源修改或新消息发生在生成过程中、取消丢弃、协议/未完整完成、UI默认/路由、离线检索/只读回查、范围/修改撤销、取消防重叠、复制保存和快捷键。全量 585 项，584 通过 / 0 失败 / 1 跳过；耗时 136.323 秒。跳过为已有 Windows 符号链接权限项。

2026-10-14 正常权限只读 GET 探测默认 http://127.0.0.1:11434 无法连接，未发送原文、未下载或推理。这只说明该地址当时不可用，不证明机器没有其他运行时/端口。模型路径用自建响应验收，真实权重、同义召回、模型幻觉/提示注入抵抗及生成速度尚待用户选定真实本地模型验证。

## 开源差距与下一方向

[Open WebUI](https://github.com/open-webui/open-webui) 和 [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm) 的模型选择、知识工作区和检索问答体验更完整。当前界面已形成聊天原文证据闭环，但缺持久问答工作区、流式模型输出、重排/ANN、多格式知识和真实模型评测。小样本离线检索的高召回不能代替语义效果。

下一 P2-D 在 GUI 与 CLI 两客户端实际需求上提供版本化只读接口，不引入任意代码插件或公开网络写库 API；最终构建并探测新开发 EXE。随后优先真实模型质量和 P1 来源内容/检索规模补齐，避免继续扩展未验收提供商。
