# P2-A 引用式知识接口验收

日期：2026-10-14。基线 bfcff2a，feature/archive-platform-v0-9；正式版本仍为 0.8.0。

## 实际交付

KnowledgeSource 从已有 Scope 读取原文，ChunkRef 绑定 MessageRef、scope_id、Unicode 字符区间和正文 SHA-256。默认 600 字符/80 重叠，支持 32–2048 长度，保留空格、换行和 emoji；不改原文。片段携带 UTC 时间、发送/接收身份、来源及消息版本。游标以消息 ID/片段末尾寻址，绑定范围、处理版本和整个范围内容摘要，变化后重新从第一页读取。

引用回查重新核验授权范围、文件身份、消息版本与片段摘要。Schema1/2/3 沿用只读精确校验；索引不写进权威归档。当前仅覆盖已归档私聊文本，群聊/媒体保持待实现。

## 验证证据

11 项新增测试覆盖 Unicode 原文/分页无遗漏和重复、相同文本不同事件、范围隔离、修改/删除失效、游标变化、参数拒绝、空范围、原库字节不变以及 Schema3 副本兼容。全量 560 项，559 通过 / 0 失败 / 1 跳过；耗时 124.219 秒。跳过为已有 Windows 符号链接权限项。

首次沙盒专项运行的迁移硬链接被 WinError 5 拒绝；未改产品规避，在正常权限下的全量回归重新验收。未读取真实账号、未迁移真实库、未调用模型。

## 与高星项目的差距及方向修正

截至本次查阅，[Open WebUI](https://github.com/open-webui/open-webui) 已有文档知识、模型配置及混合 RAG/重排；[AnythingLLM](https://github.com/Mintplex-Labs/anything-llm) 提供工作区、本地模型和知识检索体验。这些是项目自身声明，未对其私有实现或召回指标作测试。ChatArchive 目前只有可追溯聊天切片，没有语义检索/生成 UI。

下一 P2-B 先补独立索引、模型版本、增量/删除和基准，再接 UI 与生成；不能用可调用接口的存在代替检索质量证据。P1 未完成项仍待推进。
