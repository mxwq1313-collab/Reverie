# P1 Codex使用界面与功能入口验收

日期：2026-10-14。基线ac042a9，应用正式版本保持0.8.0；本阶段为独立开发版，不覆盖旧发布包。

## 改进后的使用流程

Codex页面明确分为连接→官方登录→选择归档范围→提问。运行组件路径收进默认折叠设置；连接不等于登录。未连接/未登录/没有有效身份会话/没有问题/正在回答时发送按钮按实际条件禁用，快捷问题仅填入，不自动发送；Ctrl+Enter发送，Enter换行。

新增“检查登录状态”，保留官方浏览器登录、取消、登出和模型目录。读取范围显示归档文件名、双方昵称及稳定ID。切换范围立即撤销旧工具，并异步结束旧会话清空显示；切库仍关闭连接并撤权。连接中断更新登录可用状态，错误保持可见，不显示伪成功。

对话区使用统一阅读字体和角色样式，增加快捷待办/时间总结/原消息查询。回答中的消息编号可点击回查：只读当前授权范围原记录，显示时间、双方和原文，范围外或不存在的编号明确失败；这不自动证明模型结论正确。复制保留原文与引用；保存只创建新UTF-8文件，不覆盖已有文件。没有新增跨软件持久线程恢复，当前官方线程仍为ephemeral。

归档设置新增“创建升级副本”按钮：选择新文件后调用已验收复制迁移，验证成功才打开新副本，原库保留，旧版不能打开新Schema。此入口让P0的快照/大记录批次路径可从GUI使用，不要求用户先写命令。
