# P2-B 可重建知识索引验收

日期：2026-10-14。基线 33c019d，feature/archive-platform-v0-9；正式版本仍 0.8.0。

## 交付与边界

SQLite 派生索引与权威归档分离，原文片段和向量存储在本机索引文件；应按聊天隐私资料管理该文件。索引绑定范围、源内容版本、切片/处理版本、模型/摘要/维度与度量。精确余弦扫描使用有界 top-k，不依赖额外库；不是百万级 ANN。

增量更新只计算新/变片段，复用原向量并更新昵称元信息，移除删除片段；更新在独立事务中完成。取消、模型/原文变化或计算失败回滚到上次完整索引；SQLite secure_delete 开启，不保证外部备份的删除。原文变化后的旧索引拒查，候选逐条重读范围内原文核对。索引损坏可选择新路径或显式重建；未知数据库/触发器拒绝。

offline-lexical 是离线字符 1/2-gram 特征哈希，不是训练语义模型。Ollama 使用 [官方 embed 接口](https://docs.ollama.com/api/embed)，truncate=false、实际响应维度和已安装模型摘要，限定 HTTP 回环、无代理/重定向、无自动 pull；剔除已知云模型。用户仍需保证其本机服务配置与模型来源符合本地处理意图。

## 验收

新增 11 项测试：构建/查询/原库不变、增量/删除、失败/取消/并发源变化回滚、错误范围/原库目标/处理版本、重建、未知/损坏文件、篡改片段/维度/触发器、空范围、HTTP 协议/批次/非有限数/模型版本与云模型拒绝。协议服务器为自建 HTTP fixture，没有真实模型权重或推理。沙盒 WinError10013 套接字限制通过正常权限全量复测。全量 571 项，570 通过 / 0 失败 / 1 跳过；耗时 130.656 秒。跳过为已有 Windows 符号链接权限项。

可复跑 tools/knowledge_benchmark.py：1000 条自建消息，10 个明确字面问题，每个 3 次；Recall@5=1.0，p50=67.652 ms，p95=72.841 ms，构建=0.237 s，索引=4206592 bytes；Windows10.0.26200、Python3.10.11、SQLite3.40.1。只反映当前小样本字面检索，不代表同义语义召回、大库、真实模型或多机表现。

## 开源差距与下一方向
