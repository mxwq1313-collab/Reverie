# 客户端响应、配色与侧栏帮助验收

2026-10-14；基线46bfc61；分支feature/archive-platform-v0-9；内置版本保持0.8.0。

## 行为与用途

正常客户端先建立窗口，随后恢复最近归档；关闭时取消待执行恢复，已有归档选择不会被自动恢复覆盖。嵌入式显式控制器保留同步构建，供既有调用与测试使用。

消息数据和搜索范围未变化时复用现有控件、选中文字和排版，查询仍走原只读服务以检测数据库变动；内容变化重新渲染。排版使用字体/宽度缓存，两个事件循环阶段完成测量，不嵌套刷新整个窗口；初始几何尺寸未确定时延后测量。屏幕外原文控件保留数据与复制能力，滚入可视区域时重新显示。分页像素位置、原始空白、长消息换行、上下文跳转和细滚轮规则继续覆盖。

空闲主任务轮询250ms、Codex400ms、本地知识500ms；活动请求仍分别60/100ms响应。范围切换主动撤销工具授权，工具自身仍验证当前归档版本。字体列表每个窗口只读取一次，颜色角色按表查找。

界面去除重复快捷键说明、工具占位描述、重复设置提示和无用就绪提示；保留需要用户判断的范围、数据限制、错误状态与AI发送原文提示。普通按钮为文字操作，选中导航使用细线和平面色块，联系人使用平面行与圆形头像，消息改为矩形文本面；主操作和输入保留小圆角。相关步骤集中到帮助。

新主题：暖砂、雾蓝、松绿、紫雾。选择“设置 → 外观与阅读 → 界面主题”，点击应用设置；四项均即时生效、可保存和重读。所有主题正常正文、辅助文字、选中行和主操作字色/底色的对比度检查达到4.5:1。

左侧“帮助”包含开始使用、添加与来源范围、浏览/搜索/复制、导出与文件位置、AI使用、外观与快捷键、工具与常见问题。章节导航和关键词搜索/高亮可以离线使用；Ctrl+F在帮助页聚焦帮助搜索。English设置切换帮助正文，归档原文不翻译。正文与[中文文档](USER_GUIDE.md)、[英文文档](USER_GUIDE.en.md)来自同一内容源，冻结程序内置完整正文，不依赖外部文档路径。帮助控件首次打开才构建。

## 可重复测量与限制

仅100条合成多行私聊消息，Python3.10源程序，1240×820窗口，每版3个新进程，cProfile启用，perf_counter计时。计时从Tk根窗口已建立后开始，包含工作台创建与首批100条消息恢复；不含程序加载、模块导入、Tk根初始化、真实个人库或EXE加载。运行环境一致，原始每次值保存在开发包验收目录中的performance_before.json / performance_delivered.json。

| 测量 | 修改前中位数 | 修改后中位数 |
|---|---:|---:|

| 窗口建立到首屏会话就绪 | 2241.9 ms | 1190.8 ms |
| 重复刷新100条消息 | 2041.9 ms | 74.7 ms |
| 缩放观察窗口 | 98.4 ms | 201.7 ms |
| 16ms定时器平均实际间隔 | 220.9 ms | 206.8 ms |
| 16ms定时器最大实际间隔 | 1190.1 ms | 461.5 ms |

构建与重复刷新明显改善；缩放与持续事件调度受Tk绘制和系统负载影响，本轮缩放观察值没有稳定整体提速证据。定时器仅用于记录事件循环延迟，不是屏幕帧率测量；未宣称所有操作60fps或零卡顿。屏幕外绘制的资源收敛和进入可视区恢复另有行为测试。冻结EXE进行了功能探测，尚未按同一计时方法比较EXE冷热启动；不同归档、硬件和系统DPI仍需实机复核。
