# 思绪2.0.0发布与验收

2026-10-16，用户明确授权2.0.0发布与Git提交，基于a90555c。版本号同步Python包、运行时及Windows文件/产品版本。沿用feature/sixu-mbti-ui，完成验收后创建本地v2.0.0标签；当前仓库没有远程，不上传或推送。

## 修复与行为

- 导入默认由最近50条改为所选会话全部电脑本地记录；最近条数增加至100万，全量无固定条数上限，仍受本机时间、磁盘及来源可用性约束。来源工作进程对全量/富媒体任务允许最长24小时，用户取消仍独立生效。
- 快照每批500→2000条，正文计数改为增量累加，避免每条重复汇总整批；保留8MiB正文与64MiB批文件预算、来源稳定性检查和原始快照。读取/保存数量返回界面，分批保存可取消和恢复。
- 旧归档补全只修复附件，不改变消息正文、数量、来源ID、去重哈希、现有可用附件；文件校验后写入归档资源目录，每条补全在短事务提交，网络请求不持有数据库写锁。数据库连接显式关闭。
- 取消整次任务50次、90秒联网预算。每个资源仍限制16MiB、4000万像素、30秒资源期限和8秒网络读超时；失败结果按URL/可接受摘要缓存2048项，成功内存缓存64MiB，本地已解析表情按MD5复用。
- 不扩大CDN允许列表、不降低HTTPS、不关闭证书校验；地址只从消息或已登记表情元数据获得，MD5和图像结构均须通过。商店表情缺少可验证声明、失效资源或未知编码保留缺失状态。
- 缩略图跳过GIF前16帧范围内的透明首帧，使用第一张可见帧；图片加载仍在后台且按可见区域提交，点击可打开播放窗口。

## 运行与边界

最终包位于build/sixu_2_0_0_release/release/Sixu，运行“思绪.exe”并保留_internal。旧运行包保留。验收回执置于build/sixu_2_0_0_release/evidence，不进入Git。发布包清单记录最终提交与文件摘要。

已导入旧表情需要执行一次“补全已归档表情”，仅升级EXE不会凭空生成缺失资源。软件不会把真实聊天交给Codex来下载表情。基础归档、未知来源拒绝、源文件只读和MBTI官方资料授权边界保持。
