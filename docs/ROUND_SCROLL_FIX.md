# 圆角界面与滚轮修复

2026-10-14，基线25ccc24，分支feature/archive-platform-v0-9，正式版本仍为0.8.0。

用户确认“全是方块”指按钮和区域过于方正、类似表格；“鼠标中间不灵敏”指滚轮响应慢或在某些位置不滚动。

## 可见变化

主操作/次操作、导航选中项、输入框/下拉、工具页标签、联系人卡片和AI输入区采用统一圆角；联系人头像改为圆形，气泡按明确的16逻辑像素半径绘制。按钮按内容自然宽度排版并收紧内边距，导出会话/询问AI并列，减少标题区高度；淡化工具页和表格的外框，减少大块方框感。保留真实消息文本、时间、方向、复制/选中、搜索、界面阅读设置和全部既有入口。没有更换GUI框架或增加业务功能。

## 滚轮原因与修复

旧Canvas直接使用int(delta/120)：小于120的高分辨率滚轮/触控板事件会变为0。部分事件只绑定在外框/Canvas上，鼠标位于时间、气泡边缘或设置子控件时无法传到滚动区域。

统一WheelRouter在控件自身绑定之后、原生类绑定之前处理已登记滚动区域。控件创建完成后登记，动态会话/消息及折叠设置在更新时补充登记；不在全窗口Map事件中递归修改绑定。Canvas每格按48逻辑像素移动，细小增量按比例移动，文本每格3行并累积余量。优先使用最近的文本/表格滚动区；滚到边缘时交给外层面板。未登记区域不会带动其他面板，Shift+滚轮继续交给原生水平处理。退出或销毁动态区域时清理登记。没有修改系统鼠标设置。
