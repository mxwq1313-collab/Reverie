# Codex 使用区、添加流程与响应验收

2026-10-14，基线7196607，分支feature/archive-platform-v0-9，正式版本0.8.0。

## 已实现行为

Codex名称、单一展开/收起入口，目录/身份/会话选择弹窗和当前会话/全部私聊范围控件，输入区完整模型目录与努力、快速模式选择。目录来自model/list分页，includeHidden=true，不编造模型或可用权限；按返回的supportedReasoningEfforts与defaultReasoningEffort更新选项。范围变更主动撤销旧工具读取。模型、努力和快速模式在AIRequest准备时冻结，turn/start发送model、effort和serviceTier；快速层fast，关闭时明确default以重置。模型变化复用同一授权范围的线程，变更参数不会丢弃当前流式输出。失败重试继续检查原数据与参数，不能将旧请求误发到新范围。

配置文件写入合并为250ms一次，关闭时刷新未保存项；缓存目录仅帮助重启显示，刷新可重新读取组件返回列表。连接/登录/运行组件仍在设置中，提问所需参数就在Codex输入区旁。副本存储、授权与原文查询管线不变。

图标用代码生成矢量轮廓，避免依赖符号字体。按钮保留可访问名称、键盘和悬停说明；普通操作不铺成成排块状按钮。回到最新仅阅读离开底部时浮动出现，不改变正文区域高度。空消息区域有可操作的连接/登录/提问入口，停止和发送互斥显示。

添加页三步账号/会话/归档与两步来源/预览导入。联系人为空不展示大空表，读取后显示紧凑列表；统计仅操作发生后出现。详情/限制/路径折叠到高级项，主操作位置明确。聊天原文采用没有整块底色的文本表面，自身方向细线和左右对齐保留；搜索选中、复制、时间、分页和原始空白仍可用。

隐藏页面现在grid_remove，展示页面grid；避免所有页面在堆叠下仍映射。其他页面数据结构仍保留，传统路径/旧别名继续可达。
