# 思绪：轻量参数浮层、搜索框与视觉对齐

2026-10-15。基于用户提供的五张截图实施，正式版本保持1.1.0，本地构建标识为“轻量控件版”。

按最新补充，窗口标题与左上角仅显示“思绪”，去除可见的版本号与构建后缀；内部版本与打包元数据保持1.1.0。六档强度名称依次为练气、筑基、金丹、元婴、化神、渡劫，分别映射low、medium、high、xhigh、max、ultra；仍仅展示当前模型实际支持的档位，保存和请求沿用服务端原参数。

## 界面行为

模型入口改为文字和独立图标组合：细线箭头采用原生复合按钮的垂直居中布局。未加载模型目录时显示“选择模型”；载入或切换后显示实际选中模型的名称，包括自动选择的账号默认模型，窄侧栏按可用宽度省略长名称。模型、主题及布局变化会刷新名称和箭头。

任务状态以用户可理解的中文显示会话概况、参与者、联系人查询、聊天记录查询和原文读取结果，分别保留成功与未完成状态；未知工具使用通用资料读取说明。内部工具名称只供协议使用，界面文案不包含工具标识，也不会把“查询完成”说成“找到匹配记录”。中英文沿用现有本地化。

输入区的“选择模型”打开紧凑圆角浮层，无系统标题栏和“完成”按钮。当前强度在上方居中，下面显示模型名称；点击模型可从原目录切换，滑杆只展示该模型实际支持的推理程度。左侧闪电切换快速模式，右侧回转箭头恢复默认强度；点击外部或按Esc收起。刷新模型移入模型菜单。配置变量、当前请求冻结、后续发送参数与原登录状态沿用既有管线。

联系人与消息搜索均为浅色圆角填充框，分别显示“搜索联系人…”和“搜索聊天记录…”占位文字；占位不写入搜索词，输入后按Enter搜索。移除重复的搜索文字按钮，联系人刷新改成计数行右侧的小图标。

两个搜索框采用相同字体、高度、内边距、背景与圆角。身份选择区域与会话说明区域等高，计数/刷新行与范围/日期行等高，使搜索框和下方两个列表的顶部对齐。常规下拉框改用细线V形箭头，取消箭头处的重边框外观，保留原生选择与键盘行为。

聊天标题、上下文标题和逐条消息不再常驻显示UTC+08:00；日期仍按既有北京时间转换，原时间、存储、引用与导出偏移不变。

## 验证

已实现并验证。相关界面回归144/144，0失败、0跳过；随后“选择模型”改名及星点动效的最终控件专项11/11；管理15/15。使用程序自建数据，不读取或上传真实聊天。本轮只重跑相关UI与行为测试，未重跑全部后端套件，也未重新发送真实模型请求。

新增检查覆盖：两个搜索框的实际Enter行为与对齐、无框浮层和支持程度绑定、外部点击收起、原生下拉焦点、主题/大字号/窄窗口及轻量箭头。早期布局曾用Computer Use查看合成主窗口、参数卡片并打开范围下拉；之后用户按Esc停止了界面自动操作。本次新增模型名、独立箭头和进度文案仅用程序测试与冻结包内置检查验证，未再次操作桌面。检查发现的原生Tk popdown焦点没有Python控件对象的问题，已改用Tcl焦点路径判断并加入回归。

浮层释放仅删除其自身的全局点击回调，兼容Python 3.10，并验证其他全局事件仍然可用；旧验证日志发现的清理异常已修复。最终相关回归同时将Tk回调异常视为失败，144项日志中没有该异常。
