# 思绪 2.1.0 发布与验收

2026-10-16。用户明确授权发布 2.1.0 并提交 Git。基于 56c04d3，沿用 feature/sixu-mbti-ui；发布提交与本地 v2.1.0 标签由 Git 和发行清单记录。没有远程仓库，未推送、未上传发行包。

## 用户可见变化

- 采用 ui-ux-pro-max 的界面与交互规则：细边界卡片、清晰标题、可换行操作、内联错误、实际状态反馈；正文使用系统中文字体和现有主题。用户消息居右、Codex 回答居左，生成状态继续可见。
- Codex 原生文本区支持标题、粗体、列表、引用、代码及链接，引用缩为可点击编号。隐藏排版标记，复制和历史保存仍使用精确原文；补齐非 BMP 字符后的流式定位，避免 emoji 后的文本与引用偏移。
- 归档管理、语义检索按工作顺序分区。索引恢复按钮仅在失败后出现，本地模型配置保留在 AI 设置；当前检索实现仍限定私聊，并明确说明群聊范围。
- 导入与分析报告移入“设置”。联系人与消息小窗口统一表单、取消/保存反馈；群聊和结构化媒体只读，原始 XML 默认收起，避免将群聊错误改写为私聊。
- 会话卡片删除最近消息预览，仅保留姓名、日期、简洁消息数和本人占比，群成员仍可展开。
- 新增“更新头像”：精确绑定已归档微信本人账号、用户与群来源标识，从该账号本地 head_image 缓存读取。校验格式、尺寸与内容摘要后缓存，以圆形显示；无缓存使用中性占位。电脑微信归档完成后自动尝试更新，旧归档可手动更新；不按昵称猜图，不下载头像，不改归档数据库。
- 用户提供的“小猫的混乱思绪”完整原图应用到品牌、窗口和 Windows 程序图标，仅做标准尺寸转换。原图及摘要封装在 app_logo.json，不引入图标库或新的运行依赖。

## 三个独立小工具

| 工具 | 完整操作 | 范围与边界 |
| --- | --- | --- |
| 时光胶囊 | 日期或日期段、关键词、前后一天、100条分页、选择预览、回到原文、复制、保存单条或当前页 | 沿用明确选择的本人及会话；北京时间包含起止日；保存当前页不冒充完整范围导出 |
| 随机回忆 | 条件筛选、均匀抽取、最近100条避免重复、上一条/下一条回看、清空记录、原文跳转、复制和保存 | 已全部打捞时保留上一条并提示清空重试；身份、会话或归档版本改变后旧结果不可复制/跳转 |
| 文字小工坊 | 字数/汉字/英文词/行数、取选中文字、UTF-8文件打开与保存、行尾空格和空行整理、原样查找替换、忽略大小写、撤销/重做、复制 | 文本文件打开预算1MiB；整理只作用于工具输入；整次替换作为一步撤销，不写归档 |

工具首页只做入口，各工具有独立页面与返回按钮。文字编辑可撤销，回忆读取使用独立只读快照，后台结果到达时再次核对范围和版本。

## 图一报错的原因与真实复验

本次 11:01 失败工作任务仍返回旧提示“来源在读取期间变化或存在不可读分片，请稍后重试”。当前稳定副本实现已在 56c04d3 引入，旧运行路径仍指向早期 2.0.0 包；本次使用包含该修复的 2.1.0 源码和全新发行路径。来源建立副本时逐数据库有限重试，之后使用封存、完整性校验过的不可变只读副本；附件读取期间的新消息不再使整批误报失败。各分片分别封存，并非整个微信账号同一事务时刻的快照。未核验、不可读副本、被改动副本或分片清单变化仍明确拒绝。工作进程结果新增软件版本与读取策略，便于区分新旧构建。

按同一失败任务的账号、会话与100万条读取上限，在 build/r21 私有隔离目录完成验证；这次关闭CDN，只使用本地资源，没有将真实聊天发给模型。会话当时已增长为 185,566 条：封存全部 185,566 条，未映射发送者 0，媒体处理异常 0；首次新增 185,566、重复 0、失败 0，重读新增 0、重复跳过 185,566、失败 0。原归档主文件SHA256前后相同。

附件引用 55,744 个，本地取得 13,976、未取得 41,768。缺少本地图片、视频及表情资源不等于消息导入失败，本轮没有宣称缺失资源已恢复。真实头像读取 2/2 个，缺失 0，准确绑定所选账号并保存到隔离缓存；原归档未写入。

另外已为现用归档更新本机头像缓存：5 个对应身份取得 4 个头像，1 个群头像无本地缓存；2 张会话卡片中 1 张已有真实头像。缺失项保留占位，可在微信查看该群头像后重试更新。现用归档主文件摘要仍不变；这些个人头像不进入发行包或Git。

## 缩放与绘制

合并连续根窗口布局事件，延后时间线宽度变化；只对可见消息做精确换行，离屏行保留有界估算，进入视区时重新测量并保留阅读锚点。修复隐藏行测量让出事件循环时又被展开所致的 collapsed_children 竞争。滚动条和本人消息侧标复用画布项目，避免反复删除重建；侧栏模式带宽度迟滞，减少临界宽度来回切换。“减少动画”使用静态效果。

最终自建100条长消息、连续 24 次改变窗口大小，采集 90 帧，Tk回调错误 0，大块黑色采样 0；事件循环最大间隔 105.879ms，耗时 13.71s。对照本轮较早的全量隐藏行测量方案，耗时46.036s、最大间隔313.162ms。这个结果适用于本机该场景与固定窗口内部采样区域，不是对所有显卡、视频播放及任意负载的全面保证。
