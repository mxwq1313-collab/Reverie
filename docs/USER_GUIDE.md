# 思绪使用帮助

## 2.0.0：大量记录与旧表情

添加→从电脑微信读取，默认“全部电脑本地记录”，一次覆盖所选会话本机实际可读的全部记录；也可选择最近500、5000、5万、10万或100万条。显示读取/保存条数，按2000条分批保存，不把所有消息控件同时显示。读取阶段取消不开始导入；保存阶段取消保留已提交批次，可以重新导入同一封存目录继续并去重。

旧归档显示缺失表情时，进入添加→高级设置→“补全已归档表情”，或者单击缺失表情→“补全归档表情”。沿用“从微信官方CDN补全缺失表情”开关：开启后只请求记录声明的官方资源，不发送聊天正文给Codex；关闭后仅核验已有附件，不联网。无需重新导入全部消息，不增加重复消息；已补全资源会在聊天中显示。失效地址、缺少可验证下载声明或未支持编码仍会计入未取得，不用替代图片冒充原图。

## 控件与阅读体验

按钮、输入框、搜索和下拉选择按层次使用浅底、细线及轻底边阴影，减少重复圆角框；帮助、历史和范围选择中的搜索保持一致。原生下拉列表随当前主题和字号更新，保留键盘操作。模型卡片已删除“恢复默认强度”，直接拖动或用方向键选择所需强度。

大归档启动、聊天搜索和会话切换在后台读取，读取期间可以继续操作界面；新的查询会替换旧查询。图片在接近可见区域时加载，返回已读会话或相同查询可复用内存结果，归档变化后自动失效。主界面不再显示自动生成的归档文件名，实际文件路径在归档管理中查看。按钮有按压和悬停反馈，导航侧标随页面切换；“减少动画”启用时直接更新位置。

## 1.1 媒体修复版

导航、主要操作和状态保留文字；明确的辅助操作采用图标，同屏不同辅助操作使用不同符号。鼠标停留或用 Tab 聚焦显示完整功能名。回复生成显示“千丝万绪…”。后台读取时仍可切页，写入按钮暂时锁定。

在设置的“外观与阅读”中选择字体、字号和主题，再点击“应用设置”。连续点击应用会合并为最终选择；切换保留聊天原文与选区，隐藏页面显示时使用最新设置。首次载入字体仍有绘制成本。

添加页高级设置中的“从微信官方CDN补全缺失表情”选项启用时，只取消息已有的资源地址，校验 MD5，不发送聊天正文。关闭后只读取本地缓存。重新读取包含原缺失消息的范围可去重补附件，单纯打开旧归档不会自动补回。导入详情显示取得、缺失和失败类别。过期资源或未知编码仍可能缺失。合并转发支持展开文本，内嵌媒体按已取得资源显示。


# 开始使用

## 第一次使用
1. 在“工具 → 归档管理”点击“新建归档”，选择新的 .db 文件。
2. 打开左侧“添加记录”，从电脑微信读取，或导入已有文件。
3. 回到“聊天归档”，选择查看身份与会话。

新建的1.0归档支持私聊、群聊和附件；已存在的文件不会被覆盖。

## 打开旧归档
点击“打开归档”直接阅读旧库。添加页可直接点击“导入副本文件”。读取旧归档中的群聊或媒体时，软件自动准备兼容的工作文件并保留原文件，无需手动创建升级副本。

## 阅读习惯
会话按最近消息排列，消息按时间展示，默认时区为北京时间 UTC+08:00。原文、昵称和消息方向保留。

# 添加记录与支持范围

## 从电脑微信读取
1. 保持微信已登录，点击“检测账号”。
2. 选择账号，点击刷新图标加载会话。
3. 点击联系人或群名；群名前的箭头可展开成员。
4. 选择最近50条、最近500条或全部电脑本地记录，点击“读取并归档”。

检测不等于导入。统计基于可读的本地记录；成员行用于查看群内发言统计，归档群聊请选群名。

## 从文件导入
先选择文件或目录并预览，再导入。旧JSON/CSV和交换1.0继续按原规则处理；“思绪2.0交换”支持群聊、Unicode表情、图片、贴纸、音频、视频和任意文件附件。封存快照目录可分批导入，中断后重新选择同一目录即可去重续传。

## 文件可用性
本机存在且能读取的附件才标为可用。未下载、已过期或解密失败的附件显示“原文件未获取”，消息仍保留；不会驱动微信界面下载。消息数为0的联系人不进入读取列表。来源类型未登记的记录会以来源消息卡片保留可读内容和类型编号，原始字节保存在来源快照中。

## 身份未映射是什么意思
这表示来源数据库缺少发送者编号与账号的映射，并不表示整条消息不可读。已登记的系统通知按“系统”显示，不计入身份未映射。软件优先使用已登记的群消息发送者前缀恢复身份；仍无法确定时显示“来源身份未映射”，保留正文并计入会话总数，不冒认成本人。本人占比在有未映射记录时是下限。检测只展示来源会话，导入结束后才显示实际新增、重复和失败计数。

# 浏览、搜索与复制

## 选择会话
在左侧选择查看身份，再搜索联系人或群名。群聊可展开成员；成员旁显示消息数与该成员在群内的发言占比。

## 本人消息占比
本人指当前查看身份。占比 = 本人在该会话发送的消息数 ÷ 会话总消息数；分母包括已归档的文字与非文字消息。零消息会话不会列入读取列表。归档列表统计已入库记录，电脑微信检测列表统计本地来源，两者范围可能不同。

## 搜索与上下文
输入关键词，选择当前会话或全部会话，再搜索。日期格式为YYYY-MM-DD，包含起止日期。“加载更多”继续读取；全部会话结果可以查看上下文并返回原搜索。

## 复制原文
可拖动选择文字；右键“复制这条原文”保留原始内容。附件消息显示预览或文件卡片，原始描述仍保存在归档中。滚动速度可在设置中调整。

# 导出与文件位置

## 导出完整范围
选择聊天标题右侧的“导出”，或在导出页选择当前身份、当前会话或全部归档。导出包含该范围的全部已入库消息，不受当前搜索或加载页数影响。

## HTML、TXT与附件
HTML用于离线阅读，图片、GIF表情与可播放媒体通过相对路径引用。TXT保留文本与附件路径。附件同时复制到导出目录，manifest.json记录文件大小与摘要；缺失附件会明确标注。每次输出到新目录。

## 查看或保存附件
聊天中的图片直接展示；单击图片后，可保存图片、播放动图或保存该消息的其他原文件。普通文件保留“另存附件”。语音容器、专有图片或视频编码可能需要相应播放器；保存原文件不等于本软件能解码所有格式。

## 备份与存储
备份数据库时，同时备份同名的“数据库名.media”文件夹。设置中的目录变更仅用于后续新文件，不自动搬迁已有归档。Codex历史在配置目录下的ai_history，AI登录资料与历史记录分开保存。

# AI 使用与连接

## 连接与提问
在“设置 → AI连接与模型”连接Codex，并按需登录ChatGPT。点击右上角Codex图标展开助手；这是助手的统一入口。点击侧栏的会话范围，在可搜索的面板中选择身份与会话，再点击“应用范围”。

输入区下方的同一个入口显示模型和努力程度；点击可一起调整。刷新图标读取模型目录，闪电图标切换快速模式。参数用于下一次发送，模型可用性以账号和服务端实际响应为准。

## 查看历史对话
点击保存、设置旁的历史时钟图标，可搜索历史、离线查看原回答。选择“继续对话”可恢复服务端线程；需要已连接登录，且归档、身份、会话及原文版本与历史一致。来源变化后请新建对话，旧回答仍可查看。

## 数据范围
问题和工具查到的相关私聊文字会发送给OpenAI；附件文件不会自动上传。1.0的群聊与媒体可在归档中浏览和导出；Codex只读工具仍限于明确选择的私聊文字，群聊不会混入另一份私聊范围。

## 回答与恢复
Ctrl+Enter发送。回答中的引用可回查原消息。停止或失败后的内容会保留；可取回问题编辑或重试。新对话会保存历史并清空当前上下文，模型结论仍需核对原文。

# 外观与快捷键

## 外观
设置支持浅色、深色、跟随系统，以及暖砂、雾蓝、松绿、紫雾。可调整字体、12–24逻辑像素字号、滚动速度、界面语言与紧凑导航。点击“应用设置”立即保存；联系人姓名与原文不会被翻译。

## 键盘操作
• Ctrl+F：消息搜索；帮助页内搜索帮助。
• Ctrl+Shift+F：全部会话搜索。
• Alt+←：返回搜索结果。
• ↑ / ↓、Home / End：选择联系人；Enter打开。
• Ctrl+L：展开Codex并聚焦输入。
• Ctrl+Enter：发送问题；Enter换行。
• Ctrl+C：复制选中文字；Ctrl+A选择当前消息。

## 阅读与窗口
帮助页在窄窗口中切换为章节下拉选择；正文限制行宽，标题、步骤与说明分层展示。系统缩放和跨屏效果仍受具体设备影响。

# 工具与常见问题

## 归档打不开
确认文件存在且为本项目归档库。不要直接把微信原库当成归档库。旧库可以先阅读，添加时自动准备兼容工作文件，原文件保留。

## 附件无法预览
查看是否显示“原文件未获取”。可用附件会核对摘要；原文件被删除或改变时拒绝使用。专有格式仍可保存原文件，用对应软件打开。

## 读取或导入未完成
查看导入报告中的新增、重复、失败和保留数量。读取期间来源变化会拒绝发布不稳定快照。已封存的分批目录可再次导入；已提交的来源ID会去重，不需要删除已导入消息。

## Codex无法继续历史
先连接登录，并核对原归档、身份和会话。归档原文变化会使旧线程的读取授权失效；可查看旧回答后新建对话。历史文件损坏会忽略该条，不影响其他历史。

## 操作位置
“工具”提供归档管理、导入与分析报告、本地模型与语义检索。涉及真实内容的修改只作用于当前归档副本；索引与AI回答不能替代原文。
