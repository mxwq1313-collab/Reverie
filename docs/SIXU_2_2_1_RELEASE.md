# 思绪 2.2.1 发布与验收

日期：2026-10-16。用户已明确要求发布2.2.1并上传公开仓库mxwq1313-collab/Reverie。

## 界面与使用

- 左下角交错箭头为“随机回忆”入口，使用图标按钮，保留文字语义及鼠标悬停/键盘聚焦说明。时光胶囊使用沙漏，统计使用柱形图，三者可区分。
- 点击入口打开紧凑非模态小窗口；再次点击、Esc或窗口关闭按钮收起。聊天归档保留原来的页面与选择，未抢占全局操作。
- 首要操作为“打捞一条回忆”。日期与关键词筛选默认折叠；回忆正文可选择，支持前后回看、复制、UTF-8文本保存与定位归档原文。
- 关闭再打开保留筛选、当前回忆和最近100条回看记录。归档、身份或会话范围变化会撤销旧回忆；异步返回会再次核对范围。
- 正文与操作分组，窄窗口、大字号时优先保留底部操作，正文滚动；支持浅色与深色配色。
- 工具区保留“归档管理 / 语义检索 / 文字小工坊”三项；随机回忆不再占用工具标签。
- 已删除截图中的账号检测浮动提示。检测本身继续正常执行，状态栏、进度条、结果与错误反馈仍可用。

- 修复英文Windows区域设置下中文日期标题无法显示的问题，直接组合年月日，语言切换保留既定显示形式。
