- 文字小工坊改为直接铺满可用空间的编辑页，移除编辑器外层的整页画布。查找与替换由工具栏或 Ctrl+H 打开独立非模态小窗口；Esc 或关闭收起，重开保留条件。查找、替换、撤销、重做、复制与保存沿用原来的文本操作。
- 底部文本整理操作与字数统计优先分配空间，编辑区使用剩余高度。窗口变化保留原文、选择及控件身份；最大化、还原与最小化恢复经过专项验证。
