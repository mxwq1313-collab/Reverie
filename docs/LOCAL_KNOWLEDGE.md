# 本地知识检索与证据问答

本功能只读取当前归档中已入库的私聊文本。群聊、媒体和手机未同步历史不在覆盖范围。

## 无模型时检索原文

1. 在“聊天归档”选择查看身份和联系人。
2. 打开“工具与设置 → 本地知识问答”，选择“当前会话”或当前身份所有已归档私聊。
3. 保持“离线字面检索（无需模型）”，点击“更新索引”。
4. 输入原词，点击“检索原文”，或按 Ctrl+Enter。点击结果查看原文、消息 ID、UTC 时间及发送者。

离线检索使用字符特征向量，不能保证同义问题命中；短词可能因相似度阈值不返回长文，可使用更完整原词。相似度不是结论可信度。

## 使用已有本地模型

展开本地模型设置，填写本机 Ollama 的 HTTP 回环地址，点击“读取已有模型”。分别选择适合生成向量和回答的已安装模型；同一列表不保证每个模型适合两种用途，接口会报告不支持。

需要语义检索时切到“Ollama 语义检索”并更新索引。离线字面索引也可配合本地回答模型使用。点击“本地模型回答”后，检索证据会交给已选本机服务；软件不自动下载模型。已识别的云模型不列出，请自行核查本机服务/模型的来源与配置。[Ollama 官方文档](https://docs.ollama.com/api/chat) 说明服务协议。

回答标为“模型推断”，每项结论带证据编号，下方展示对应原文。程序核对引用身份、范围和版本，不保证模型推断正确；应人工核对。证据不足时不生成结论。取消会立即撤销展示，当前本地 HTTP 请求返回后丢弃结果；期间不启动重叠任务。

## 索引、更新和保存

切换会话/归档/模型或原文变化后旧结果清除。原文变化后的旧索引拒绝查询，点击“更新索引”增量复用向量并移除删掉的片段。“重新计算全部索引”重新计算当前配置；损坏文件可退出软件后仅删除对应派生索引，再重新建立。

索引保存在应用数据目录的 `knowledge_indexes`，按文件/身份/会话/处理和模型配置分隔。索引含聊天片段和向量，可删除重建，不是原始消息备份。不要把索引或复制/保存的回答证据上传到公开仓库。保存只创建新 UTF-8 文件，不覆盖旧文件；复制/保存前重新核对原文。

原始归档不因知识操作被初始化、迁移或改写。既有 Codex 助手仍在独立标签页使用自己的登录和授权范围。

命令行第二客户端、stdio v1.0 接口和扩展边界见 [知识 API 说明](KNOWLEDGE_API.md)；本阶段实际验收及后续路线见 [P2 阶段报告](P2_ACCEPTANCE.md)。
